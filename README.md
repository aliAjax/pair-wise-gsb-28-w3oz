# 司机运力承诺台（配送任务拖拽排班）

把配送任务拖进司机班次，系统按顺序重算到达时间并给出送达承诺；违反窗口、载重新增整单拒绝，连续作业满 4 小时强制插入休息，配送后承诺锁定，调班必须带原因生成新版本并完整保留原派单。

- 技术栈：React 19 + Vite + TypeScript + Ant Design 5 + dnd-kit + Zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则自测：`npm run test:rules`（19 个纯引擎断言）
- 数据持久化：浏览器 `localStorage`（key：`driver-capacity-commitment-board:v1`）

## 三层分离

| 层 | 目录 | 职责 | 不允许包含 |
| --- | --- | --- | --- |
| 规则层 | `src/rules/` | 时间换算、车程矩阵、顺序重算、休息插入、超时/超载整单拒绝、锁定承诺、版本、存量冲突 | React、localStorage、中文 UI 文案之外的副作用 |
| 持久化层 | `src/store/storage.ts`、`src/store/seed.ts` | localStorage 读写/校验/重置、演示数据 | 任何排班规则判断 |
| 界面层 | `src/ui/`、`src/App.tsx` | 订单登记、司机/班次维护、拖拽时间轴、冲突清单、版本切换、调班弹窗 | 自行计算到达时间或载重（一律调规则层） |

`src/store/useBoard.ts` 是编排层（Zustand）：把界面动作交给规则层纯函数校验，通过后写状态并调持久化层，拒绝时落一条冲突记录。

## 规则说明（见 `src/rules`）

1. **订单登记**：商圈、装卸分钟、重量、可送达时段（起止）。
2. **司机运力**：每名司机可维护多个班次（上班/下班时间、班次载重 kg）。
3. **顺序重算**：从班次开始时刻由场站出发，逐单累加「车程（商圈间矩阵，无向对称，同商圈为 0，缺省 30 分钟）+ 装卸」；到达早于窗口开始则等待。
4. **整单拒绝**：到达晚于可送达时段止（或完成超出班次结束）记超时分钟；装入后累计重量超过班次载重记超出重量 kg；触发任一条件，该单**整单**不进入序列，原派单不变。
5. **强制休息**：连续工作（车程+装卸）累计满 240 分钟，下一段行驶前插入 30 分钟休息；若该休息会覆盖已锁定任务，拒绝（休息冲突）。
6. **配送锁定**：点「配送锁定」后到达/完成分钟固化为承诺，任务不可再拖拽；改订单时段或班次运力后，存量排班由规则实时重算，冲突立即进入冲突清单。
7. **调班版本**：点「调班」必须填写原因，基于当前派单深拷贝出新版本（`parentVersion` 指向上一版），原版本只读保留，可随时切换核对。
8. **刷新一致性**：承诺时间随版本持久化，刷新后规则引擎用相同输入重放，保证「排班 = 承诺」。

## 冲突清单字段

来源（拖入拒绝/移动拒绝/存量）、订单号、司机、类型（超时/超载/休息冲突）、**超时分钟**、**超出重量 kg**、说明、时间。
